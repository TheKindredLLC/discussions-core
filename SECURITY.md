# Security Policy

## Supported Versions

The following versions of `kindred-discussions-core` are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our library seriously. If you believe you have found a security vulnerability in `kindred-discussions-core`, please report it to us by following these steps:

1.  **Do not** open a public issue on GitHub.
2.  Send an email to `b.vogtman@outlook.com` with a detailed description of the vulnerability.
3.  Include steps to reproduce the issue and any potential impact it may have.

We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution. We ask for your patience and cooperation as we work to address the issue.

We follow a responsible disclosure policy and will coordinate with you on the timing of any public announcements.
